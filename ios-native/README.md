# تطبيق عمولات نجيب سليم - نظام iOS الأصلي (Native iOS App)
# Naguib Selim Sales Rep Commissions - Native iOS (SwiftUI)

تطبيق iOS أصلي مبني بلغة **Swift** وإطار عمل **SwiftUI** متطابق بنسبة 100% مع تطبيق الأندرويد، مع تجربة مستخدم متقدمة ودعم كامل للغة العربية (RTL) والإنجليزية (LTR)، والوضع النهاري والليلي، وتسجيل الدخول ببصمة الوجه (Face ID) أو الإصبع (Touch ID).

---

## 📱 مميزات التطبيق (Features)

1. **تصميم وهوية نجيب سليم 1:1**:
   - ألوان الهوية الرسمية (درجات البني الدافئ `#744C27` والذهبي الداكن `#D2A574` والخلفيات الأنيقة).
   - زر تحويل الوضع النهاري/الليلي (أيقونة اللمبة في دائرة) بتأثير حركي سلس (Spring Animation).
   - شاشة تحميل وشعار NS المتحرك في المنتصف بدقة عالية.

2. **تسجيل الدخول والأمان**:
   - دعم حفظ الجلسة على هذا الجهاز (Remember Me).
   - زر بصمة الوجه / الإصبع (Face ID / Touch ID) مربع الشكل بجوار زر تسجيل الدخول مباشرة.
   - زر واتساب المباشر المتناسق للتواصل مع الإدارة (`+20 1277909022`) عند مواجهة أي صعوبة في الدخول.
   - إلغاء قسم "نسيت كلمة المرور" غير الضروري.

3. **لوحة العمولات التفاعلية (4 أقسام رئيسية)**:
   - **الرئيسية (Summary)**: بطاقة Hero مائلة بتدرج لوني فخم، عمولة الشهر الحالية، معدل التقدم اليومي، شريط تحقيق الهدف (Target Bar)، توقعات نهاية الشهر (Run Rate).
   - **المبيعات (Sales)**:
     - 4 خيارات رئيسية (حسب اليوم - حسب العميل - حسب الفاتورة - حسب المنتج).
     - عند فتح أي قسم يظهر عنوان حديث مع شريط بحث عصري (Expandable Modern Search Bar) بأيقونة بحث تتمدد بسلاسة لكتابة كلمات البحث مع تصفية فورية.
   - **التحصيل (Collections)**:
     - إجمالي التحصيل، ومصادر التحصيل (مدفوعات، شيكات، مقبوضات).
     - قسم "عملائي: المستحق عليهم اليوم" مع أيقونة تمثل مديونيات وحسابات العملاء (`CustomerBalancesIcon`).
   - **الكشف (Statement)**:
     - تفصيل الشرائح (A, B, C)، البضائع الراكدة، التسويات والمكافآت، والمبلغ الصافي المستحق.

4. **شريط التنقل السفلي الحديث (Modern Floating Bottom Bar)**:
   - 5 عناصر مع زر NS الدائري العائم في المنتصف للعودة للرئيسية.
   - أيقونة المبيعات الصاعدة (`SalesRisingIcon`).
   - أيقونة التحصيل وحسابات العملاء (`CustomerBalancesIcon`).

5. **شاشة الحساب والإعدادات (Account)**:
   - بيانات المندوب والوظيفة وتاريخ انتهاء الجلسة.
   - تغيير كلمة المرور مباشرة من التطبيق.
   - فحص واختبار وصول الإشعارات.
   - مظهر التطبيق (تلقائي مع النظام / فاتح / داكن).
   - تبديل لغة الواجهة بين العربية والإنجليزية مع عكس اتجاه الواجهة (RTL / LTR) لحظياً.

6. **نظام التحديث الإجباري الذكي (Mandatory Update)**:
   - نافذة منبثقة ذكية تظهر عند وجود إصدار جديد مطلوب.
   - عند الضغط على "تحديث"، يتم توجيه المستخدم مباشرة إلى صفحة التحميل الرسمية:  
     `https://ns-scw.bayoumi.dev/ar/get-app`

## 🚀 كيفية الفتح والتشغيل (How to Run)

### 1. فتح المشروع مباشرة في Xcode:
المشروع مجهز بالكامل بملف مشروع Xcode القياسي:
```bash
open ios-native/NSCommissions.xcodeproj
```

### 2. إعداد شهادة التوقيع (Signing & Capabilities):
1. في شريط Xcode الجانبي، اضغط على المشروع الرئيسي **NSCommissions**.
2. اختر Target: **NSCommissions**.
3. توجه إلى تبويب **Signing & Capabilities**.
4. اختر حساب المطور الخاص بك في **Team** (أو Personal Team).
5. تأكد من تفعيل:
   - `Face ID` (مضاف تلقائياً في `Info.plist` تحت `NSFaceIDUsageDescription`).

### 3. التشغيل على المحاكي أو جهاز حقيقي:
- اختر جهاز محاكي (مثال: iPhone 15 Pro أو iPhone 16) أو جهازك الفعلي المتصل.
- اضغط على **Run** (`⌘ + R`) أو زر التشغيل بالأعلى.

## 📂 الهيكل البرمجي (Architecture & File Structure)

```text
ios-native/
├── NSCommissions.xcodeproj/       # مشروع Xcode القياسي الجاهز للتشغيل
│   └── project.pbxproj
├── project.yml                     # إعدادات XcodeGen في حال الرغبة بإعادة التوليد
├── NSCommissions/
│   ├── NSCommissionsApp.swift     # نقطة انطلاق التطبيق الرئيسية (@main)
│   ├── Info.plist                  # إعدادات الحزم والأذونات (FaceID, Schemes)
│   ├── Assets.xcassets/            # الأيقونات والشعارات والألوان
│   │   ├── AppIcon.appiconset/     # أيقونة التطبيق الرسمية بدقة 1024x1024
│   │   ├── ns_mark.imageset/       # علامة NS الرسمية
│   │   ├── ns_wordmark.imageset/   # شعار نجيب سليم الكتابي
│   │   └── AccentColor.colorset/   # درجات اللون الرئيسي
│   ├── Theme/
│   │   └── Theme.swift             # لوحة الألوان (NsColors)، الخطوط والتنسيقات النقدية
│   ├── Data/
│   │   ├── Models.swift            # نماذج البيانات والمحولات (JSON Parsers)
│   │   ├── SessionStore.swift      # إدارة الجلسة المحلية، تذكرني، والبصمة
│   │   └── ApiClient.swift         # الاتصال بالسيرفر، فحص التحديثات، والإشعارات
│   └── UI/
│       ├── Components.swift        # المكونات الرسومية المخصصة (شريط البحث، الأيقونات، اللمبة، محمل NS)
│       ├── AppViewModel.swift      # إدارة حالة التطبيق (State Management)
│       ├── MainShellView.swift     # الحاوية الرئيسية للتطبيق ودعم الـ RTL
│       ├── LoginView.swift         # شاشة تسجيل الدخول المتطابقة 1:1
│       ├── CommissionsView.swift   # حاوية العمولات والشريط العلوي واختيار الشهور
│       ├── RepDetailView.swift     # تفاصيل العمولات، المبيعات (مع البحث)، التحصيل، والكشف
│       ├── AccountView.swift       # شاشة إدارة الحساب والإعدادات
│       ├── BottomNavBar.swift      # شريط التنقل السفلي العائم
│       └── MandatoryUpdateDialog.swift # نافذة التحديث الإجباري
```
