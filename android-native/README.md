# NS Commissions — Native Android App (`Kotlin + Jetpack Compose`)

تطبيق أندرويد أصلي (**100% Native Kotlin + Jetpack Compose + Material 3**) لنظام **عمولات المندوبين — نجيب سليم (Naguib Selim Sales Rep Commissions)**.

## المميزات الرئيسية
- **واجهة أصلية بالكامل (Jetpack Compose + Material 3)**:
  - دعم كامل للغتين العربية (RTL) والإنجليزية (LTR) مع التبديل الفوري.
  - وضع نهاري وليلي وتلقائي حسب النظام بهوية نجيب سليم البصرية (درجات البني الدافئ والذهبي).
- **شاشات المندوب والمدير**:
  - تسجيل الدخول بالبريد الإلكتروني أو اسم المستخدم (`nsr305`) أو الاسم في الشيت.
  - شاشة العمولات بأربعة تبويبات أصلية: **الملخص، المبيعات (مع رسم بياني أصلي Canvas وتفاصيل الأيام/العملاء/الفواتير/المنتجات)، التحصيل، وكشف العمولة التفصيلي**.
  - ملخص الفريق للمديرين والمسؤولين مع الفلترة والبحث.
  - حفظ آخر نسخة محلياً على الهاتف للعمل بدون إنترنت (**Offline Cache**).
- **شاشات المسؤول (Admin) الأصلية بالكامل**:
  - **إعدادات العمولة الشهرية**: تعديل شرائح الأسعار، النظام القديم، نسب الراكد والديجيتال مع البحث المباشر في أصناف Odoo، شروط الحوافز والخصومات، سلم مكافأة المبيعات، ربط المندوبين بمستخدمي Odoo، وإرسال إشعارات التعديل.
  - **إدارة حسابات المندوبين**: إنشاء الحسابات من شيت المستهدفات، تعديل الاسم المعروض واسم المستخدم، تفعيل/إيقاف الحسابات، إلزام تغيير كلمة المرور، واختيار نسخة تحميل أندرويد الافتراضية على الموقع.
- **الإشعارات والأمان**:
  - تخزين مشفر للجلسة (`EncryptedSharedPreferences`) مع تجديد تلقائي لـ Bearer Token.
  - خدمة خلفية (`WorkManager`) لفحص الإشعارات كل 15 دقيقة وعرض إشعارات أندرويد الأصلية.

## المعرّف والتوقيع
- **Application ID**: `com.naguibselim.commissionsapp` (يُثبّت جنباً إلى جنب مع نسخة الـ WebView `com.naguibselim.commissions`).
- **Signing Key**: يستخدم نفس مفتاح التوقيع الرسمي في `../android-signing-key/ns-commissions-release.jks`.

## بناء ملف الـ APK محلياً
```bash
gradle -p android-native --no-daemon assembleRelease
```
ينتج ملف الـ APK الموقّع في:
`android-native/app/build/outputs/apk/release/app-release.apk`
ويُنشر على الموقع في:
`public/downloads/ns-commissions.apk`
